# 浏览器插件

自用的浏览器扩展合集，每个插件一个目录，各自独立打包发布。

| 插件 | 说明 | 平台 | 状态 |
|---|---|---|---|
| [force-dark](force-dark/) | 强制任何网站进入深色模式，无论其自身是否有深色主题 | Chrome / Edge | v1.1.2 |

## 目录约定

每个插件目录自成一体，包含：

```
<插件名>/
├── manifest.json     扩展清单
├── build.sh          打包脚本，产出 dist/<名>-<版本>.zip，含完整性自检
├── README.md         该插件的说明、原理、已知限制
├── _locales/         多语言文案
└── store/            商店提交用的素材与文案
```

隐私政策统一放在 `docs/<插件名>/privacy-policy.html`，通过 GitHub Pages 对外提供链接，
商店提交表单需要填这个 URL。

## 加一个新插件

1. 建目录 `<插件名>/`，按上面的约定放文件
2. 复制一份 `force-dark/build.sh` 改改就能用
3. 在 `docs/<插件名>/` 下加隐私政策页，并在 `docs/index.html` 里挂上链接
