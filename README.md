# Force Dark — 全站强制深色模式

Chrome / Edge 通用的 Manifest V3 扩展。无论网页自身有没有深色模式，都能强制切换为深色。

## 安装（开发者模式加载）

Chrome：地址栏打开 `chrome://extensions` → 右上角开启「开发者模式」→「加载已解压的扩展程序」→ 选择本文件夹。

Edge：地址栏打开 `edge://extensions` → 左下角开启「开发人员模式」→「加载解压缩的扩展」→ 选择本文件夹。

两者代码完全一致，不需要分别打包。

## 功能

- **全局总开关**：一键对所有网站生效 / 关闭。
- **按站点设置**：跟随全局 / 开启 / 关闭 / 强制（域名级别，记忆保存）。
- **智能模式**（默认）：检测页面背景亮度，本身已是深色的站点自动跳过，不会被"反转成白色"；需要时可对单站选「强制」。
- **微调**：亮度、对比度、灰度、护眼暖色。
- **快捷键**：`Alt+Shift+D` 切换当前站点。
- 图片、视频、canvas、iframe 以及无文字容器的背景图会做反向滤镜，保持原本颜色。
- `document_start` 注入，先暗后判定，基本没有白屏闪烁。

## 实现原理

对 `:root` 应用 `filter: invert(100%) hue-rotate(180deg)`：invert 把亮色变暗色，hue-rotate 把被反转的色相转回原样，所以蓝色还是蓝色。媒体元素再套一层同样的滤镜抵消回来。

同时强制 `color-scheme: light`，避免浏览器自身的深色表单控件被二次反转。

## 已知限制

- 给 `:root` 加 filter 会让 `position: fixed` 元素以根元素为包含块，极少数页面的固定定位布局可能出现偏移。
- CSS 类里设置的渐变背景不做反转（反转后通常更难看）。
- 浏览器内置页面（`chrome://`、`edge://`、扩展商店）无法注入，这是浏览器限制。
- Canvas 里绘制的内容整体反转，做不到按内容区分。

## 文件结构

```
manifest.json     扩展清单（MV3）
background.js     service worker：快捷键、角标、默认值
content.js        注入滤镜、深色检测、背景图扫描
popup/            弹出面板 UI
_locales/         多语言文案（en / zh_CN），界面跟随浏览器语言
icons/            图标
store/            商店提交用的素材和文案
build.sh          打包脚本（含完整性自检）
```

## 多语言

界面语言跟随浏览器：英文环境显示 "Force Dark — Dark Mode for Every Site"，
中文环境显示"Force Dark — 全站强制深色模式"，弹出面板同理。
文案都在 `_locales/<语言>/messages.json`，加语言只需复制一份目录改文案，代码不用动。

## 分发给别人

`./build.sh` 生成 `dist/force-dark-<版本>.zip`，用于下面任一方式。

### 1. 直接发压缩包（最快，适合少数几个人）

对方解压到一个**不会被删掉**的固定目录（删了扩展就失效），再按上面的「开发者模式加载」步骤选该文件夹。

代价：Chrome / Edge 每次启动会弹「请停用以开发者模式运行的扩展程序」的提示，点关闭即可，不影响使用；没有自动更新，换版本要重新发包。

### 2. 商店「未公开发布」（推荐，私下分享）

上传同一个 zip，可见性选 **Unlisted / 未公开**：不出现在搜索和分类里，只有拿到链接的人能安装。安装后走正常更新通道，没有开发者模式的警告。

- Chrome Web Store：开发者账号一次性 $5，`https://chrome.google.com/webstore/devconsole`
- Edge 加载项：免费，`https://partner.microsoft.com/dashboard/microsoftedge`

两个商店互相独立，同一个 zip 各提交一次。首次审核通常几天，本扩展申请了 `<all_urls>`，要在表单里写清用途（"需要在所有网站注入 CSS 滤镜以实现强制深色"）并声明不收集任何用户数据。

商店还需要：128×128 图标（已有）、至少一张 1280×800 或 640×400 的截图、简短描述。

### 3. 企业策略批量安装（公司内网场景）

管理员通过 `ExtensionInstallForcelist` 策略推送，员工电脑自动安装、不可卸载。需要域管理权限，自建更新服务器或指向商店 ID。

### 关于 .crx 文件

Chrome 和 Edge 从 Chrome 33 起就屏蔽了「拖 .crx 到扩展页安装」这条路，非商店来源的 crx 会被直接拦下。所以不要指望打 crx 发给别人，走上面 1 或 2。
